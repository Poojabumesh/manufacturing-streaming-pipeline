# Mini FlavorMetrics – Streaming Manufacturing Pipeline

This project demonstrates an end-to-end streaming data pipeline inspired by manufacturing analytics systems.

## Architecture
- Kafka for streaming ingestion
- Spark Structured Streaming for validation, aggregation, and deduplication
- Snowflake as the analytics warehouse
- Streamlit for operational dashboards
- Docker for local deployment

## Use Case
Simulated IoT sensor data and batch-style QA data are ingested, validated, and aggregated to provide near-real-time visibility into production batches and quality metrics.
